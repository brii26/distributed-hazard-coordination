# Bonus network results

`tests/bonus/net-latency.sh` writes one timestamped set per run here: `net-latency-<UTC time>.txt` (the evidence) and `net-latency-<UTC time>.prom` (the same numbers in Prometheus text format). The generated files are ignored by git (see `.gitignore`), copy the ones the report cites. This README is the only tracked file.
